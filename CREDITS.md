# Credits

Geo Challenge is a fan-made tribute to *Geo Challenge* by Playfish (2008–2011). It contains no Playfish code or artwork.

## Data and libraries

- Country and state shapes: [Natural Earth](https://www.naturalearthdata.com/) (public domain) via [world-atlas](https://github.com/topojson/world-atlas) and [us-atlas](https://github.com/topojson/us-atlas) (ISC)
- Country metadata: [mledoze/countries](https://github.com/mledoze/countries) (ODbL 1.0)
- Country flags: [flag-icons](https://github.com/lipis/flag-icons) (MIT)
- US state flags: [Wikimedia Commons](https://commons.wikimedia.org/) (public domain)
- [D3](https://d3js.org/) and [topojson-client](https://github.com/topojson/topojson-client) (ISC)
